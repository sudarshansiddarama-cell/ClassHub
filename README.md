# ClassHub

ClassHub is a single-page class space with notes, papers, case studies, notices,
class chat, community posts, and an AI study assistant.

- `index.html` — the entire front-end app.
- `supabase/` — Edge Functions and database migrations.
- `tests/` — Node tests for the AI chat helpers.

The AI assistant setup (Groq key, Edge Function deployment, migration) is
documented in [AI_CHAT_SETUP.md](AI_CHAT_SETUP.md).
